# Logo ASPJ-PE

## Instruções para adicionar o logo

Por favor, adicione o arquivo de logo da ASPJ-PE com o nome `logo.png` neste diretório (`/public/`).

### Especificações recomendadas:
- **Nome do arquivo:** `logo.png`
- **Formato:** PNG com fundo transparente
- **Dimensões mínimas:** 200x200 pixels
- **Dimensões recomendadas:** 400x400 pixels ou superior
- **Formato quadrado ou circular** para melhor visualização

### Onde o logo é usado:
1. **Favicon do site** (ícone na aba do navegador)
2. **Cabeçalho público** - Na página inicial e demais páginas públicas
3. **Sidebar** - Menu lateral da área administrativa (40px de largura)
4. **Tela de login** - Lado esquerdo da tela de login (200px de largura)
5. **Formulário de pré-cadastro** - Cabeçalho do formulário (150px de largura)
6. **PDF de adesão** - Gerado automaticamente no documento PDF

### Como adicionar:
1. Coloque o arquivo `logo.png` neste diretório: `/public/`
2. O logo será automaticamente carregado em todas as páginas
3. Não é necessário reiniciar o servidor de desenvolvimento

### Fallback:
Enquanto o logo não for adicionado, as referências ao logo permanecerão, mas a imagem não será exibida. O sistema continuará funcionando normalmente.
